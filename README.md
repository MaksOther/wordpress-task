# Auth Forms for Elementor

Плагін додає в Elementor віджет Auth Form для входу, реєстрації та відновлення пароля

Можна показати окрему форму входу, форму реєстрації або обидві у вкладках. Форми надсилаються через AJAX, а помилки з’являються біля полів. Після входу чи реєстрації користувач переходить на вказану сторінку. Якщо адресу не задано, поточна сторінка перезавантажується.

## Що є у плагіні

- Вхід за email або ім’ям користувача, опція «Запам’ятати мене».
- Реєстрація з перевіркою email, імені користувача та підтвердження пароля.
- Автоматичний вхід після реєстрації. Новий користувач отримує роль Subscriber.
- Відновлення пароля через стандартний лист WordPress.
- Кнопка показу та приховування пароля.
- Google reCAPTCHA v3, яку можна підключити в налаштуваннях.
- Український переклад.

У налаштуваннях віджета можна змінити підписи, підказки в полях, назви кнопок і вкладок, повідомлення про успіх. Адреси переходу після входу та реєстрації задаються окремо.

У вкладці Style налаштовуються кольори, шрифти, відступи, поля та кнопки. Є налаштування для різних розмірів екрана.

## Вимоги

- WordPress 6.0+
- PHP 8.1+
- Elementor 3.5+ — достатньо безкоштовної версії

## Встановлення

1. Встановіть та активуйте Elementor
2. В адмінці WordPress відкрийте **Плагіни → Додати новий → Завантажити плагін**
3. Виберіть `auth-forms-for-elementor.zip`, встановіть та активуйте плагін
4. Для реєстрації користувачів увімкніть **Налаштування → Загальні → Будь-хто може зареєструватися**.
5. Відкрийте сторінку в Elementor і додайте віджет **Auth Form** з категорії «Загальні»
6. Виберіть тип форми, змініть потрібні тексти та вкажіть адреси переходу

Також можна розпакувати папку `auth-forms-for-elementor` у `wp-content/plugins/` і активувати плагін через адмінку.

Перевіряти вхід і реєстрацію потрібно на опублікованій сторінці як гість, наприклад у приватному вікні браузера. У редакторі Elementor форми не надсилаються.

## Налаштування reCAPTCHA

Створіть ключі reCAPTCHA v3 у [консолі Google](https://www.google.com/recaptcha/admin) та додайте Site key і Secret key у **Налаштування → Auth Forms**.

Після заповнення обох ключів reCAPTCHA перевірятиме вхід, реєстрацію та відновлення пароля. Без ключів форми працюють без reCAPTCHA.

## Як влаштований код

```text
auth-forms-for-elementor/
├── plugin.php          Підключення файлів і запуск плагіна
├── uninstall.php       Видалення налаштувань плагіна
├── widgets/            Віджет і його налаштування в Elementor
├── ajax/               Обробка входу, реєстрації та відновлення пароля
├── classes/            Основні класи, налаштування, reCAPTCHA і виведення форм
├── includes/           Допоміжні функції та HTML-шаблони
├── assets/             CSS і JavaScript
└── languages/          Файли перекладу
```

Налаштування Elementor та HTML форм розділені. Клас `AFE_Widget` відповідає за контролі в редакторі, а `AFE_Form` отримує їхні значення і виводить потрібний шаблон.

Для кожної форми є окремий AJAX-обробник. Спільні перевірки винесені в `AFE_Ajax`: стан авторизації, nonce та reCAPTCHA. Далі обробник перевіряє поля й викликає відповідні функції WordPress — `wp_signon()`, `wp_create_user()` або `retrieve_password()`.

JavaScript надсилає дані через `fetch()` і показує відповідь сервера. jQuery не використовується. Обробники подій прив’язані до `document`, тому продовжують працювати після повторного виведення віджета в редакторі.

Тексти віджета зібрані в `includes/functions.php`. Звідти беруться стандартні значення та назви текстових налаштувань Elementor.

## Перевірка даних

Дані форм перевіряються на сервері. Кожна форма має свій nonce. Текстові поля та email очищуються перед обробкою, а значення екрануються перед виведенням у HTML.

Для роботи з користувачами використовуються функції WordPress, власних SQL-запитів немає. Адреса переходу з форми перевіряється через `wp_validate_redirect()`.

Якщо реєстрацію вимкнено в налаштуваннях WordPress, створити користувача через віджет також не можна.

## Переклади

У папці `languages/` є шаблон `.pot` та український переклад `.po` / `.mo`.

Підписи форм можна змінити прямо в Elementor. Серверні повідомлення про помилки перекладаються через файли локалізації.

## Що врахувати

Для відновлення пароля на сайті має працювати надсилання листів WordPress.

Якщо використовується кешування сторінок, для сторінки з формою краще налаштувати виняток: у кеші може залишитися застарілий nonce, через що форма попросить оновити сторінку.
